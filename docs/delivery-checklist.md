## ۱. اجرا در محیط توسعه

```bash
# بک‌اند (ریپوی جدا)
dotnet run --project src/Digibit.Api --urls http://localhost:5072

# پنل
npm start            # http://localhost:4200
```

ورود: `admin@digibit.local` / `Admin@12345`

- `API_BASE_URL` در توسعه روی `http://localhost:5072/api/v1` است.
- برای PostgreSQL، قبل از اجرا `dotnet ef database update` را روی ریپوی بک‌اند اجرا کنید
  (migration `BackofficeContract`).
- دیتابیس SQLite توسعه با `EnsureCreated` ساخته می‌شود؛ برای شروع از صفر فایل
  `digibit.db` را حذف کنید.

## ۴. موارد آگاهانه متفاوت با متن تسک

- **`C07` (mock backend) منسوخ شد.** با اتصال بک‌اند واقعی، interceptor و fixtureها حذف
  شدند. `C07` را «انجام‌نشده» حساب نکنید.
- **قرارداد پاسخ:** بک‌اند پاسخ مسطح می‌دهد، نه `{data, meta}`؛ `ApiService` هر دو را
  می‌خواند. اگر envelope دقیق لازم است، یک تغییر جدا در بک‌اند است.
- **توکن‌ها:** access و refresh در `localStorage` هستند. تسک `D03/D05` کوکی httpOnly را
  پیشنهاد می‌کرد؛ بک‌اند فعلی هر دو را JSON برمی‌گرداند. این یک بدهی امنیتی ثبت‌شده است.
- **`B17`:** ماتریس ۳۲۰/۳۷۵/۷۶۸/۱۲۸۰/۱۹۲۰ و overflow افقی در e2e پوشش دارد؛ تست
  دستگاه واقعی و screen reader دستی باقی است.
- **`P14`** همین سند است.
