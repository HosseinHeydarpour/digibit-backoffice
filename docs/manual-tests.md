# چک‌لیست تست دستی — صف G (دسته‌بندی و برند)

> تاریخ: ۶ نوامبر ۲۰۲۶
> محیط: `npm start` روی `http://localhost:4200` با mock API (`useMockApi: true`)، بدون بک‌اند
> مرورگر: Chromium 152 (مرورگر داخلی OpenCode)
> دامنه: G01 تا G07

## چطور دوباره اجرا کنیم

1. `npm start` را اجرا کنید و به `/categories` و `/brands` بروید.
2. داده‌ها از mock می‌آیند؛ رفرش صفحه همه‌چیز را به حالت اولیه برمی‌گرداند.
3. هر مورد را با دادهٔ ساختگی خودتان تکرار کنید و تیک بزنید. شکست‌های جدید را زیر «ایرادها» ثبت کنید.

- جریان‌هایی که در این پاس اجرا شدند سبزند.
- یک ایراد جزئی پیدا و همان‌جا رفع شد: **G08-01** (ارقام لاتین در هشدار حذف برند).
- موارد اجرانشده در همان بخش با `[ ]` و دلیل مشخص شده‌اند؛ Firefox در این محیط نصب نبود.
