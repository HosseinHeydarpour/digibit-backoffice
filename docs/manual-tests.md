> محیط: `npm start` روی `http://localhost:4200` با mock API (`useMockApi: true`)، بدون بک‌اند

## چطور دوباره اجرا کنیم

1. `npm start` را اجرا کنید و به `/categories` و `/brands` بروید.
2. داده‌ها از mock می‌آیند؛ رفرش صفحه همه‌چیز را به حالت اولیه برمی‌گرداند.
3. هر مورد را با دادهٔ ساختگی خودتان تکرار کنید و تیک بزنید. موارد جدید شکست را زیر «ایرادها» ثبت کنید.

## ایرادها

### G08-01 — ارقام لاتین در هشدار حذف برند (رفع شد)

- **قبل:** «۲ محصول» به‌صورت `2 محصول` با رقم لاتین چاپ می‌شد.
- **بعد:** `formatDigits(item.productCount)` در `brand-list.ts` استفاده می‌شود و متن «۲ محصول» است.
- **کامیت:** `d1cdf39 fix(brands): print the product count in Persian digits`
- **تست:** `brand-list.spec.ts` هر دو شرط وجود «۲ محصول» و نبود «2 محصول» را می‌سنجد؛ ۸۵۰ تست سبز.
- **وضعیت:** بسته شد.
